# Personal Portfolio Website

This is my personal portfolio website built to showcase my skills, projects, education, and contact details.

## Live Demo

🔗 [View Portfolio](https://bavishya-portfolio.lovable.app/)

## About

This portfolio represents my journey as an Information Technology student and highlights the projects I have worked on. It is designed to give recruiters and visitors a quick overview of my technical skills and work.

## Features

- Personal introduction
- Skills section
- Projects showcase
- Education details
- Contact information
- Responsive design

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn-ui
